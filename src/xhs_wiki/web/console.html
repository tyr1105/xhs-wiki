定时设置

引擎和整理模型

LLM Wiki 引擎的整理模型在 LLM Wiki 应用的设置 → LLM Models 里选择和配置；要换模型请回到 LLM Wiki 里改。

换成 API 方式或修改密钥，请点「重新设置」。

改了引擎或模型之后要提示：新设置只影响之后整理的内容。

重新走一遍首次设置：可以换知识库位置、引擎、整理模型和密钥。已整理的内容不会删除。换知识库位置时，本工具生成的内容会搬到新位置（新位置要是空文件夹或还不存在）；原文件夹里你自己放的其他文件不会动。

在哪些 AI 工具里提问

勾上的工具会装好查询技能（问一句先翻收藏、附出处、查不到直说）。Claude Code 和 Codex 命令行实测过；其他工具按各家官方文档的技能目录安装，还没实测。取消勾选只撤掉本工具写进去的技能文件；你自己放的文件、别人写的同名技能都不会覆盖或删除。

语音转写

保存后缺的模型会自动在后台下载（进度显示在页面顶部），已下载的另一个模型不会被删除。

欢迎使用 xhs-wiki

几步设置之后，它会每天自动把你的小红书收藏整理成知识库

第 1 步 · 知识库放在哪里

整理好的 Markdown 知识库会存到这个文件夹。默认放在你的用户主目录下。

如果之前已经有知识库，换位置时会把本工具生成的内容（索引.md、暂缓.md、主题、来源和隐藏的 .xhs-wiki 文件夹）搬过去；原文件夹里你自己放的其他文件不会动。新位置要是空文件夹或还不存在的文件夹。不能用主目录本身、"文稿""桌面""下载"这类系统文件夹本身、系统目录或程序包（它们里面的子文件夹可以）。

第 2 步 · 选择整理引擎

轻量引擎（推荐）

直接生成 Markdown 知识库，用 Obsidian 或任何编辑器打开就能看；速度快，不依赖别的软件。缺点是没有图谱和版本管理。

LLM Wiki 引擎（进阶）

用 LLM Wiki 桌面应用整理（开源，nashsu/llm_wiki），有图谱、问答，整理用的模型在 LLM Wiki 里选，支持 Anthropic、OpenAI 等 API 和 Claude Code、Codex。需要先安装 LLM Wiki，并保持它在后台运行。

LLM Wiki 检查通过 ✓

第 3 步 · 整理模型

提交后输入框会立即清空；Key 不会出现在页面、日志或状态里。

整理用的模型在 LLM Wiki 的设置 → LLM Models 里选择，xhs-wiki 不保存你的密钥。

  1. 在 LLM Wiki 的设置 → LLM Models 里，添加或选择一个提供方，按需填好密钥（支持 Anthropic、OpenAI 等 API 和 Claude Code、Codex）；
  2. 把「Ingest model（整理用模型）」选成这个提供方；
  3. 回到这里，点「重新检查」看检查结果，再用「测试」按钮试一次真实整理。
用 Claude 5 系列模型（如 claude-haiku-5-5）时，不要用内置的「Anthropic (Claude)」选项（会被接口拒绝）。请添加自定义提供方（Add custom provider）：协议选 Anthropic-compat，Endpoint 填 https://api.anthropic.com，模型填 claude-haiku-5-5，再把「Ingest model」选成这个自定义提供方。

检查结果

还没检查

「测试」会在知识库里放一条虚构示例笔记，由 LLM Wiki 用你选的模型整理一遍；结束后示例来源文件会自动删除，LLM Wiki 随后会把它整理出的示例页面一并清理，不会留在知识库里。

第 4 步 · 扫码登录小红书

点击「获取二维码」开始扫码

用小红书 App 扫这个码完成登录；图片每 15 秒自动刷新。

同时会弹出一个写着「登录专用窗口」的小窗口，不用管它，扫这里的二维码就行；登录成功后它会自动关闭。

第 5 步 · 首次导入多少收藏

●
最近 20 条（推荐，先看效果）

先把最近收藏整理出来看看效果，之后每天新收藏都会自动跟进。

○
全部收藏

把已有的收藏全部整理进知识库。

全部整理需要较长时间，并会占用模型额度（调用次数按收藏数量增加）。

第 6 步 · 在哪些 AI 工具里提问

知识库是普通的 Markdown 文件，能读本机文件的 AI 工具都能查。勾上的工具会装好查询技能：你问一句，它先翻你的收藏，回答附上出处，查不到会直说。Claude Code 和 Codex 命令行实测过；其他工具按各家官方文档的技能目录安装，还没实测。之后也能在控制台里改。
